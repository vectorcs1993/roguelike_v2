# Система ИИ для врагов

## Обзор
Реализована система искусственного интеллекта для врагов в roguelike игре. Враги теперь имеют различные поведения: ожидание/блуждание, патрулирование, охрана, и боевые действия при обнаружении игрока.

## Реализованные компоненты

### 1. Класс EnemyAI (`src/game/EnemyAI.js`)
Основной класс ИИ, управляющий поведением врагов.

#### Состояния ИИ:
- **IDLE**: Ожидание/блуждание - враг находится в спокойном состоянии
- **ALERT**: Тревога - враг заметил игрока, но ещё не вступил в бой
- **COMBAT**: Бой - враг атакует игрока
- **FLEE**: Бегство - враг пытается убежать (пока не реализовано полностью)

#### Типы поведения:
- **WANDER**: Случайное блуждание в пределах заданного радиуса
- **GUARD**: Охрана позиции - враг стоит на месте
- **PATROL**: Патрулирование между заданными точками

### 2. Обновлённый класс EnemyTeam (`src/game/EnemyTeam.js`)
Команда врагов теперь управляет ИИ для каждого врага:
- Автоматически создаёт экземпляры EnemyAI для каждого врага
- Определяет поведение на основе типа врага (из EnemyData.js)
- Обновляет ИИ каждого врага в методе `update()`

### 3. Боевая система в классе Character (`src/game/Character.js`)
Добавлены боевые характеристики и методы:
- `attack(target)`: Атака цели с проверкой дистанции, точности и расчётом урона
- `takeDamage(amount, damageType)`: Получение урона
- `die()`: Смерть персонажа
- `heal(amount)`: Восстановление здоровья

## Как работает ИИ

### Цикл обновления:
1. **Восприятие**: Каждый кадр враг проверяет поле зрения на наличие игроков
2. **Принятие решения**: На основе состояния выбирается действие
3. **Выполнение**: Движение или атака с учётом доступных AP

### Логика поведения:

#### В режиме IDLE:
- **WANDER**: Случайное движение в пределах `wanderRadius`
- **GUARD**: Стоит на месте, иногда "осматривается"
- **PATROL**: Движение по заданным точкам

#### При обнаружении игрока:
1. Враг переходит в состояние ALERT
2. Запоминает последнюю известную позицию игрока
3. Переходит в состояние COMBAT
4. Начинает преследование и атаку

#### В режиме COMBAT:
1. Проверяет возможность атаки (дистанция, линия видимости, AP)
2. Если может атаковать - атакует
3. Если не может - двигается к цели
4. Если цель скрылась, преследует до последней известной позиции

## Настройка ИИ для разных типов врагов

ИИ автоматически настраивается на основе данных из `EnemyData.js`:

### Примеры:
- **Враги с дальней атакой** (MOLD): Поведение GUARD, предпочитают оставаться на месте
- **Быстрые враги** (RUNNER): Поведение PATROL, активно перемещаются
- **Медленные враги** (FATSO): Поведение WANDER, медленно блуждают

## Расход AP (Очков Действий)

ИИ учитывает систему AP так же, как и игрок:
- **Движение**: Тратит `moveAPCost` AP за шаг
- **Атака**: Тратит `attackAPCost` AP за атаку
- **Ожидание**: Если AP закончились, враг ждёт следующего хода

## Тестирование

### Как проверить работу ИИ:
1. Запустите игру: `npm run dev`
2. Откройте http://localhost:9001/
3. Подойдите к врагу на расстояние его поля зрения (обычно 8 клеток)
4. Наблюдайте реакцию:
   - Враг должен заметить вас и начать движение к вам
   - При приближении на дистанцию атаки - атаковать
   - Тратить AP на действия

### Консольные сообщения:
В консоли браузера будут выводиться сообщения о действиях ИИ:
- `Создан ИИ для [имя врага]: поведение [тип]`
- `[имя врага] атакует [имя цели]!`
- `[имя врага] наносит X урона [имя цели]`

## Дальнейшее развитие

### Планируемые улучшения:
1. **Кооперативное поведение**: Враги могут координировать атаки
2. **Использование окружения**: Враги могут использовать укрытия
3. **Тактическое поведение**: Флангирование, отступление
4. **Специальные способности**: Использование уникальных умений врагов

### Оптимизации:
1. **Кэширование путей**: Уменьшение вычислений поиска пути
2. **Приоритет целей**: Выбор наиболее опасных целей
3. **Эвристики**: Улучшение алгоритмов принятия решений

## Известные ограничения

1. **Линия видимости**: Сейчас всегда возвращает `true` для упрощения
2. **Бегство**: Режим FLEE пока не реализован
3. **Смерть врагов**: Удаление мёртвых врагов из игры требует доработки
4. **Баланс**: Параметры атаки и защиты нуждаются в балансировке

## Интеграция с существующим кодом

ИИ интегрирован с минимальными изменениями:
1. `EnemyTeam.update()` теперь вызывает ИИ для каждого врага
2. `Location.updateTeams()` передаёт необходимые параметры
3. `GameLoop` продолжает работать без изменений

## Заключение

Система ИИ успешно реализована и готова к использованию. Враги теперь:
- Имеют различные поведения в зависимости от типа
- Реагируют на появление игрока в поле зрения
- Атакуют с учётом дистанции и типа атаки
- Тратят AP на действия, как и игрок

Система модульна и может быть легко расширена для добавления новых поведений и улучшений.
